# DBS-Labs

This repository contains all the lab tasks and assignments for the **Database Systems** course. 

## 🛠️ Tools Used
* **SQL Server / MySQL Workbench** (Ya jo bhi aap use kar rahe ho)
* **ERD Design:** Draw.io / Lucidchart
* **Environment:** Laragon / XAMPP

## 📂 Contents
The repository is organized by weekly labs:
* **Lab 01:** Introduction to Databases & ERD Basics
* **Lab 02:** Data Definition Language (DDL) Queries
* **Lab 03:** Data Manipulation Language (DML) Queries
* **Lab 04:** Database Normalization (1NF, 2NF, 3NF)
* **Lab 05:** Complex Joins & Subqueries

## 📝 Description
The goal of this repository is to maintain a record of SQL scripts, database schemas, and normalization exercises completed during the semester.
