# 🔍 Lab 06: Comparison & Logical Operators

## 📖 Overview
This repository contains the first part of my SQL filtering implementations. The script establishes an HR database and utilizes fundamental comparison and logical operators to extract specific data subsets based on strict business rules.

## 🧠 Concepts Applied
* **Comparison Operators:** Used >, <=, =, and != to evaluate numeric thresholds and exact text matches.
* **Logical Operators:** Applied AND to enforce multiple overlapping conditions, and OR to broaden search parameters across different columns.

## 📁 Files Included
* `2024-SE-37-Lab06-Filters.sql`: The primary SQL script containing the database setup, schema creation for the Employee table, data initialization, and all Part A tasks.

## 🚀 How to Run
Execute the .sql script in your preferred database environment. The script is entirely self-contained; it will automatically build the filters_lab database, populate the employee records, and run the 8 filtering queries in sequence.
